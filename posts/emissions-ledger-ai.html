Emissions Ledger AI: a small public interface for climate accountability

A note on a ChatGPT-built site that turns corporate emissions into a structured ledger: useful because it treats climate information as something to compare, question, and annotate rather than something to decorate.

DATE: 19 JUL 25 TYPE: SITE NOTE STATUS: ARCHIVED
CONTENTS 01 / CLAIM 02 / INTERFACE 03 / CAVEAT

01 / The useful part is the ledger, not the AI.

The site presents itself as an emissions ledger: a place where climate claims can be organized into rows, comparisons, and accountable summaries. That framing matters. Emissions data is often either trapped in PDFs or flattened into corporate language. A ledger makes a different promise: each claim should have a place, a label, and ideally a traceable source.

What I like about the experiment is its refusal to behave like a glossy climate dashboard. The important gesture is editorial. It asks the reader to move through structured evidence, not to admire a chart. For a public-facing tool about emissions, that restraint is a strength.

KEY IDEA

A climate interface should lower the cost of skepticism. If the user cannot see what is known, estimated, missing, or inferred, the interface is only producing confidence theater.

02 / The interface should make uncertainty visible.

An AI layer can help summarize disclosures, compare categories, and translate technical terminology. But the design has to keep the machine in a narrow role. It should help arrange the evidence, not become the evidence. The best version of this site would separate reported numbers, model-assisted interpretation, and open questions into visibly different rows.

That is why the ledger metaphor is valuable. A ledger is not just a table; it is a discipline. It implies entries, dates, sources, revisions, and responsibility. The more climate software borrows that discipline, the less likely it is to become another attractive but unverifiable dashboard.

What the page format should preserve

Reported dataSeparate from interpretation
AI summaryUseful, but labeled
Missing evidenceShown as a first-class state

03 / The caveat is part of the product.

The source project could not be inspected from the local filesystem in this environment, so this post treats the public site as the artifact and records the intended reading rather than a code audit. That limitation belongs inside the note. For personal writing, admitting the boundary is cleaner than pretending omniscience.

The larger lesson still holds: AI climate tools should be designed like public notebooks. They should be readable, skeptical, and revision-friendly. The point is not to make emissions feel simple. The point is to make the complexity harder to hide.
